MLA - Marketplace Listing Automation (Windows, versão beta)
==========================================================

Requisitos
- Windows 10 ou 11 (64 bits), 4 GB de RAM (8 GB recomendados), 1 GB livre em disco + espaço para as fotos.
- Microsoft Edge (já vem no Windows).

Instalar
- Dê dois cliques em MLA-Setup-<versão>.exe. Não precisa ser administrador.
- Programa: %LOCALAPPDATA%\Programs\MLA     Dados: %LOCALAPPDATA%\MLA (nunca apagados pelo instalador)

Atualizar
- No MLA: Atualizações -> Verificar agora -> Baixar e instalar. O arquivo baixado é conferido (SHA-256), o MLA
  fecha, a nova versão é instalada e o MLA abre de novo. Antes de atualizar o banco, o MLA faz um backup.
- Ou execute o instalador da versão nova por cima (feche o MLA antes).

Desinstalar
- Configurações do Windows -> Aplicativos instalados -> "MLA - Marketplace Listing Automation" -> Desinstalar.
  Os dados são mantidos. Para apagar também os dados (irreversível), na pasta do programa:
  desinstalar.cmd -RemoverDados -ConfirmarRemocaoDeDados

Aviso do Windows (SmartScreen)
Esta versão não tem assinatura digital de código. O Windows pode mostrar "O Windows protegeu o computador".
Confira o código SHA-256 enviado junto com o instalador antes de escolher "Executar assim mesmo".

Diagnóstico
- Logs: %LOCALAPPDATA%\MLA\logs (mla.log, instalador.log). Não contêm senhas nem códigos de acesso.
- Autoteste: "%LOCALAPPDATA%\Programs\MLA\MLA.exe" --self-test
