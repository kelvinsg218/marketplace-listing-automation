# MLA 0.1.2-beta

Mesmo conteúdo da 0.1.1-beta, com o canal de atualizações definitivo: as versões novas são publicadas nas
releases do repositório público de apresentação do MLA (só o instalador e o código SHA-256; o código-fonte
continua privado). A partir desta versão, **Atualizações → Verificar agora** encontra as próximas versões sozinho.

## O que a versão beta tem
- Aplicativo Windows instalável por usuário (sem administrador); dados em `%LOCALAPPDATA%\MLA`, preservados em
  atualizações e na desinstalação.
- Catálogo, importações (CSV, Excel, JSON, XML, PDF, ZIP, pastas de fotos), empresas separadas, edição em lote com
  prévia, histórico de alterações, exportação de planilha.
- Mercado Livre pela API oficial: conectar a conta (sem informar senha ao MLA), importar anúncios, sugerir
  categoria, ver atributos obrigatórios e **validar sem publicar**.

## Importante
- A publicação de anúncios no Mercado Livre pelo MLA está desligada nesta versão.
- Instalador sem assinatura digital: o Windows pode exibir o aviso do SmartScreen. Confira o SHA-256.
- Quem instalou a 0.1.1-beta deve instalar esta versão por cima (a 0.1.1-beta procurava atualizações em outro
  endereço); os dados são mantidos.
