# MLA 0.1.1-beta

## Novidades
- **Mercado Livre pela API oficial:** conecte a conta em Marketplaces → API oficial (autorização no site do
  Mercado Livre, sem informar a senha ao MLA). Depois: importar os anúncios da conta para o catálogo, sugerir
  categoria, ver os atributos obrigatórios da categoria e **validar o anúncio no Mercado Livre sem publicar**.
- Atualizações pelo próprio app (Atualizações → Verificar agora), com conferência SHA-256 do arquivo baixado.
- Tela "Versão e atualizações" com as pastas do programa, dos dados e dos logs.

## Importante
- A publicação de anúncios no Mercado Livre pelo MLA continua desligada nesta versão.
- O banco de dados é atualizado para a versão 9 ao abrir (backup automático antes).
- Seus dados (catálogo, contas, configurações, fila e histórico) são mantidos.
