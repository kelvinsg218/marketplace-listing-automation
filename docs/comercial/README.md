> Organizamos e preparamos catálogos de fornecedores para publicação em marketplaces, reduzindo o trabalho manual
> de cadastro e revisão.

foi testado na versão 0.2.0 (outubro de 2026); o que ainda não existe está dito com clareza.

## Em que ponto o MLA está

| Nível | Situação | Motivo |
|---|---|---|
| Pronto para demonstração | **Sim** | Fluxo completo com dados fictícios, cenário de 300 produtos medido, 230 testes automatizados aprovados |
| Pronto para piloto supervisionado | **Sim, com as condições do checklist** | Instalador testado; dados isolados por empresa; exportação em planilha intermediária; revisão humana em todas as etapas |
| Pronto para distribuição comercial | **Não** | Publicação real no Mercado Livre e na Shopee não verificada; executável sem assinatura digital; licença ainda não aplicada; instalação não testada em máquina limpa |
